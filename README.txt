PWA VISITAS TECNICAS SNF

1. Publique estos archivos en un sitio HTTPS, por ejemplo SharePoint con alojamiento web permitido, Azure Static Web Apps, GitHub Pages o cualquier servidor web corporativo.
2. Abra la URL publicada en el celular.
3. Android/Chrome: menu > Agregar a pantalla de inicio o Instalar aplicacion.
4. iPhone/Safari: Compartir > Agregar a inicio.

Importante:
- Los datos se guardan localmente en el navegador del dispositivo.
- La app funciona sin conexion despues de la primera carga.
- Abrir correo usa mailto y no adjunta el PDF automaticamente. Use Guardar como PDF y adjuntelo, o conecte un backend/Power Automate para adjuntar y enviar automaticamente.
- Para produccion, agregue autenticacion, base de datos, control de acceso y politica de privacidad.
